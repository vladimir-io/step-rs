FAQ

What am I looking at?
Coaxial / stepped bores: cylindrical faces on a shared axis (multi-diameter holes on a print).
Does the file leave my machine?
No. Parse + detect run in WASM in a Web Worker. Static site only.
Formats / units?
Part 21 AP203 & AP214 · .step .stp .p21 · lengths in mm.
CAM? G-code? Editing?
No. Hole callout extraction only. Always verify against the drawing.
